# 柴犬軍団

スマホの縦画面で、柴犬の隊長と豆柴の隊列が前へ進み、指で左右に動かすゲーム。
道の門をくぐると豆柴が増え、前から来る猫の群れを撃ち、最後の猫を倒せばクリア。

## 遊ぶ

**https://yasufabric.github.io/shiba-gundan/** （スマホの縦画面推奨）

## 遊び方

説明は出さない。最初から隊列が道にいて、弾は前に飛び続ける。指を左右に滑らせると、隊長ごと動く。

- 豆柴は1匹から。門は青（`+` `×`）と赤（`−` `÷`）。弾が1発当たるたびに、その門の数字が1増える。赤い門も撃ち続けると青に変わる。うまく選んでいるときの匹数だと、その変化に約2.5秒かかる。数字が変わるときは門が光って跳ねる。最初の加算の組は、どちらをくぐっても増える青い門だけ。15秒以内に、撃っても ×2 のままの青い × が一度出る。赤い門は、始まってから15秒をすぎてから出る。15秒をすぎた × は、撃って育てても ×2 で止まる。
- 一番いい門の手前にドラム缶があることがある。撃つと壊せる。隊列がぶつかると豆柴が減る。
- 弾は隊列の正面にだけ飛ぶ。隊列の横幅は道の3分の1までで、それ以上増えた分は後ろへ伸びる。画面に描く豆柴は80匹までで、超えた分は間隔を詰めて、頭上の数字を大きくする。
- 猫は前から群れで来る。後半の群れの大きさは固定で、実際の匹数では変えない。群れには薄い列があり、そこへ寄ると減りが少ない。隊列に重なった猫だけが、1匹につき豆柴を1匹連れていく。薄い列に寄ると1つの群れで約5%減り、門の列に留まると約25%減る。門を半分外して厚い列にいると、1つの群れで3割以上減る。3面の盾猫は正面の弾を盾で受け、触れると3匹減る。0匹で負け。1タップで同じステージのやり直し。頭上の匹数は左右の端でも画面の中に収まり、隊長には重ならない。
- 最後にボス猫。奥からゆっくり歩いてきて、およそ20秒で隊列に届く。届いたときにまだ生きていれば負け。体力は面ごとの固定倍率で、その場の匹数では変えない。上手いとボス前は約440匹で、残り時間は1面で約11秒、2面で約8秒、3面で約4秒、4面で約2.7秒。4面までは短くなる。5面から8面は約2.4秒で、4面より長くはならない。門を半分外すと1面と2面はぎりぎり勝ち、3面からは負ける。クリア画面の数字は、届くまでに残っていた秒。ボス戦のあいだ、画面の隊長アイコンを押すとロケット弾が飛び、体力をまとめて削る。
- クリア画面のあと、次の面へ進む。豆柴は1匹に戻る。負けたら1タップで同じ面のやり直し。2面は門が左右に揺れ、門の上にいないとその増減は入らない。最初の揺れは小さな青い門。3面は盾の猫、4面はボスが2体。5面からはその3つが重なり、猫の体力は 0.15 ずつ上がる。倍率は1面を1として、2面 1.36、3面 1.53、4面は1体 1.16、5面から8面は1体 1.029（残り約2.4秒になるよう逆算）。新しい要素は、その面の最初の10秒に安全な形で一度出てから、あとで本番になる。右上の数字が今の面。タイトルはいつも1面から。いちばん進んだ面は端末に残る。
- 左上の **おと** でミュート。初期状態は鳴っていて、保存が消音のときだけ止まる。効果音も曲も Web Audio の合成のみ。指を離したときに鳴り始め、ボスが近づくほど速く、音が増える。着信音を消していても鳴る。

## 技術スタック

- [Vite](https://vitejs.dev/) + TypeScript（開発サーバー・ビルドのみ、フレームワークなし）
- HTML5 Canvas 2D
- 効果音は Web Audio API。音声ファイルも実行時ライブラリもなし
- 隊長はマッスルひらりと同じ柴犬（[deep-three](https://github.com/yasufabric/deep-three) の絵）
- 表示フォントは [Dela Gothic One](https://fonts.google.com/specimen/Dela+Gothic+One)（SIL Open Font License、`src/assets/fonts/OFL.txt`）

## 開発

```bash
npm install
npm run dev
```

`npm run dev` は `--host` 付き。公開パスは `/shiba-gundan/` なので、
ローカルでは `http://localhost:5173/shiba-gundan/` を開く。
スマホは同じ Wi-Fi の LAN URL、PC では幅 390 前後。

## ビルド

```bash
npm test
npm run build   # tsc --noEmit のあと vite build で dist/ を生成
npm run preview
```

GitHub Pages へのデプロイは `main` への push で `.github/workflows/deploy.yml` が行う。
リポジトリの Settings > Pages > Build and deployment > Source を **GitHub Actions** にしておく。
